Frequently asked questions

Is ChatWrapped really free?

Yes — no accounts, no subscriptions, no paid tiers. It runs entirely as a static site.

Are my chats uploaded anywhere?

No. Files are read with the browser File API and parsed in a Web Worker on your device. There is no backend that could receive them. You can verify this in your browser's network tab during import.

Which formats are supported?

WhatsApp TXT exports (Android and iOS) and Telegram Desktop machine-readable JSON exports. HTML exports and media ZIPs are on the roadmap.

Does it work offline?

Yes — after your first visit the app shell, parsers and analytics code are cached, so the core workflow works without a connection.

What about group chats?

Fully supported. You can include or exclude any participant, anonymize names and filter by date range before analyzing.

Do the statistics prove anything about a relationship?

No. ChatWrapped reports counting statistics — message totals, activity rhythms, emoji frequencies. They are playful facts about activity, never judgments about people.
