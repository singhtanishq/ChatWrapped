How to Export a Telegram Chat

Telegram’s export feature lives in Telegram Desktop — the free desktop app for Windows, macOS and Linux. Exporting produces a JSON file with the full conversation, which ChatWrapped parses for your recap.

Step by step

  1. Install Telegram Desktop from desktop.telegram.org or your package manager, and log in. (The mobile apps don’t offer JSON exports.)
  2. Open the conversation or group you want to export.
  3. Click the ⋮ menu in the top-right corner and choose Export chat history.
  4. In the export dialog, select the Machine-readable JSON format. You can leave media unchecked for a small, fast file — text, stickers and attachments are recorded in the JSON either way.
  5. Click Export. Telegram writes a result.json (in a folder if you included media).
  6. Drop the result.json into the ChatWrapped analyzer.

JSON or HTML?

Telegram offers two export formats. HTML is for human reading; JSON is for software. ChatWrapped needs the JSON version — if you accidentally exported HTML, the analyzer will tell you immediately and you can re-export. Exporting again takes seconds since Telegram remembers your options.

What’s inside result.json

  • Chat name and type (personal chat, private group, supergroup).
  • Every message with wall-clock date, sender, text (as formatted parts) and attachment references.
  • Service messages — joins, pins, calls — which ChatWrapped keeps out of message totals.
  • Anonymous admin messages via the “actor” field in groups.

Troubleshooting

“Export chat history” is missing

Update Telegram Desktop — the feature has been in stable releases for years, but very old builds hide it.

The file is huge

Media files dominate export size. Re-export with media unchecked; ChatWrapped needs only the JSON. Files up to 200 MB are accepted, and a 10 MB JSON parses in a couple of seconds.

Secret chats

Telegram’s cloud chats export normally. Secret chats are device-bound and are not part of the desktop export — that’s by design of Telegram’s security model.

Where did the file go?

Telegram asks for a destination folder before exporting — the default is your Downloads folder. The JSON is named result.json; if you included media it sits next to a photos/ or files/ folder you can ignore.
