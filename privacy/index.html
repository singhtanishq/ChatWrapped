Privacy Policy

Last updated: November 17, 2026

ChatWrapped was built privacy-first: the entire application is a static site and all conversation processing happens in your browser. This policy explains exactly what that means — and what it doesn’t.

The short version

Your uploaded conversations are processed entirely in your browser. ChatWrapped does not upload your chat files to its servers.

No account. No tracking cookies. No analytics scripts. No third-party requests during processing. No error reporting service. Nothing about your messages is stored after the tab closes unless you explicitly save a recap summary.

What the app processes, and where

When you import a chat export, the file is read with the browser’s File API and parsed in a Web Worker on your device. Parsing, statistics, story generation and card rendering all run locally. The app makes no network request that contains any part of your conversation — you can verify this in your browser’s network inspector at any time; our own automated audits check exactly this on every build.

What is stored on your device

  • Session memory (default): parsed conversations live in the tab’s memory and disappear when you close or reload it.
  • Saved recaps (opt-in): if you choose “Save current recap summary”, a small aggregate record (message counts, date range, top emoji) is stored in your browser’s IndexedDB. Message text is never included.
  • Service worker cache: the app’s own static files are cached so it works offline. This is app code, not data.
  • Deletion controls: the Privacy Center can delete any saved recap, all saved recaps, or the whole session at any time.

What the hosting provider may process

ChatWrapped is hosted on GitHub Pages. Like any website, requesting the site’s static files exposes standard technical information (IP address, user agent, timestamps) to the hosting provider, which processes it under its own infrastructure policies. ChatWrapped adds nothing to that: there is no custom analytics, no logging of content, and no third-party script that could observe your visit. We do not claim that “absolutely nothing” is ever recorded by any infrastructure — that would be dishonest; we claim the app itself sends nothing beyond normal static-file requests.

What we never do

  • We never receive, store or transmit your chat files or message content.
  • We never send conversation text to AI services or any other third party.
  • We never put chat content in URLs.
  • We never use cookies, fingerprinting, session recording or advertising.
  • We never require an account, email address or payment.

Children’s privacy

ChatWrapped does not knowingly collect any personal data from anyone — there is simply no data collection to regulate. It is a tool you run on your own files.

Open source, verifiable

The entire application is open source at https://github.com/singhtanishq/ChatWrapped. The privacy architecture is documented in the repository (docs/privacy/PRIVACY_ARCHITECTURE.md), and the automated browser audit that verifies “no chat content leaves the browser” is part of the test suite.

Changes to this policy

If the privacy architecture ever changes, this policy will change with it and the “last updated” date above will reflect that. We will never add data collection quietly.

Contact

Questions or a privacy concern? Open an issue at https://github.com/singhtanishq/ChatWrapped.
