Telegram Chat Wrapped

Telegram keeps your conversations in the cloud — but your memories live in the messages. ChatWrapped reads Telegram Desktop’s machine-readable JSON export and builds accurate statistics, a personalized story and shareable cards. Free, private and processed entirely in your browser.

What ChatWrapped understands in a Telegram export

  • Formatted messages — links, mentions, hashtags, custom emoji and bot commands are flattened into clean text for analysis.
  • Attachments — photos, videos, voice messages, audio files, stickers and polls are detected as media events (captions and sticker emoji still count).
  • Service messages — joins, pins, title changes and calls are separated from ordinary message totals.
  • Anonymous admins — messages sent via the “actor” field in groups are attributed correctly.
  • Groups and personal chats — both export types work, including “Saved Messages”.
  • Edge cases — messages without dates, malformed entries and forwarded messages produce transparent warnings, never silent omissions.

Exporting the right file

ChatWrapped needs the machine-readable JSON output from Telegram Desktop — not the HTML version. The full walkthrough is in the Telegram export guide. In short: Telegram Desktop → open the chat → ⋮ menu → “Export chat history” → choose the format Machine-readable JSON → export.

Privacy, verified

Your uploaded conversations are processed entirely in your browser. ChatWrapped does not upload your chat files to its servers.

The JSON file is parsed in a Web Worker on your device. Nothing is transmitted — you can verify it in the network tab. Nothing persists after the tab closes unless you explicitly save a recap summary. Details in the privacy policy and metrics guide.

Telegram + WhatsApp in one place

Used WhatsApp with one friend and Telegram with another? Load both exports in the same session and use the Compare view to line up message volume, activity patterns, response times and top emoji side by side — with sample sizes shown so unlike conversations aren’t compared dishonestly.
